지난 주보

주보를 고칠 때마다 날짜별로 이 컴퓨터에 자동 보관됩니다. 열기는 그 주보를 다시 고칠 때, 이번 주로 복사는 작년 성탄절 주보처럼 예전 내용으로 새 주보를 시작할 때 씁니다.

AI 번역 설정

설교 제목을 영어로 옮길 때 Anthropic의 AI(Claude)를 씁니다. 처음 한 번만 API 키를 넣으면 됩니다.

키 받는 방법

  1. console.anthropic.com에 가입하고 결제 수단(충전)을 등록합니다.
  2. API Keys 화면에서 Create Key를 눌러 나온 키(sk-ant-로 시작)를 복사합니다.
  3. 아래 칸에 붙여 넣고 저장을 누릅니다.

알아 두면 좋은 것

  • 키는 이 컴퓨터의 인터넷 창에만 저장되고, "파일로 저장"한 주보 파일에는 들어가지 않습니다.
  • 제목 한 번 번역에 드는 비용은 몇 원 정도입니다.
  • 번역할 때 설교 제목과 본문 구절 위치만 AI에 보냅니다.
  • 번역이 마음에 안 들면 영어 제목 칸에서 바로 고치면 됩니다.

주보 만들기 사용법

매주 하는 일

  1. 다음 주 주보를 누릅니다. 날짜가 한 주 넘어가고, 섬김 안내표가 한 칸씩 당겨지고, 성경읽기 진도가 비워집니다. 나머지 내용은 지난주 그대로 남아 있습니다.
  2. 왼쪽 칸에서 바뀐 것만 고칩니다. (설교 제목·본문, 성경읽기, 교회소식, 목장 순서지)
  3. 인쇄 · PDF를 누릅니다. 인쇄 창에서 용지 A4 · 가로 · 여백 없음 · 배경 그래픽 켜기로 맞추고, 양면 인쇄는 짧은 쪽으로 넘기기를 고릅니다. PDF로 저장하려면 프린터를 "PDF로 저장"으로 바꿉니다.
  4. 홈페이지로 보내기를 누르면 홈페이지 "교회 소식" 페이지에 이번 주 주보 그림과 교회소식이 올라갑니다. 처음 한 번은 "교회 홈페이지" 안의 site 폴더를 골라 주세요. (그림 파일만 필요하면 이미지로 저장)
  5. 지난 주보는 날짜별로 자동 보관됩니다. 지난 주보에서 다시 열거나, 예전 주보 내용으로 이번 주 주보를 시작할 수 있습니다. 다른 컴퓨터로 옮길 때는 파일로 저장 → 파일 열기를 쓰세요.

처음 한 번만: 교회 · 로고 · 디자인

  • 교회 · 교단 · 로고 칸에서 교회 이름, 슬로건, 교단을 고릅니다. 교단 공식 마크는 교단 홈페이지에서 받은 그림 파일을 심볼 파일 올리기로 넣어 주세요.
  • 로고가 있는 교회는 로고 파일 올리기, 없는 교회는 로고 만들기에서 상징·색·글꼴·배치를 골라 만듭니다. 만든 로고는 PNG로 저장해 현수막·홈페이지에도 쓸 수 있습니다.
  • 디자인 칸에서 색(숲·하늘·클래식·노을)과 표지 모양(그림/글씨)을 고릅니다.
  • 절기 주일(대림절·성탄절·신년·사순절·부활절·성령강림절·맥추감사·추수감사)에는 날짜를 보고 색과 표지 그림이 자동으로 바뀝니다. 절기가 끝나면 평소 디자인으로 돌아옵니다. 추수감사주일이 셋째 주인지 넷째 주인지는 디자인 칸에서 정해 주세요.

글 쓰는 규칙

  • 줄 맨 앞에 -를 쓰면 점이 붙은 목록이 됩니다.
  • **굵게**처럼 별표 두 개로 감싸면 굵은 글씨가 됩니다.
  • 목장 순서지 "말씀 요약"은 빈 줄로 나누면 요약 1, 요약 2…로 번호가 붙습니다.
  • 목장 순서지는 설교 원고를 붙여 넣거나 원고 파일(Word·PDF·txt)을 올리고 ✨ 원고를 목장용 요약 · 나눔 질문으로 만들기를 누르면 요약 3개와 질문 3개가 채워집니다. 한글(hwp) 원고는 열어서 전체 복사 → 붙여넣기 해 주세요. 꼭 읽어 보고 다듬어 주세요.
  • 영어 제목은 ✨ AI 번역을 누르면 자동으로 채워집니다. 처음 한 번 위쪽 AI 설정에서 키를 넣어 주세요.

알아 두면 좋은 것

  • 쓴 내용은 이 컴퓨터의 인터넷 창에 자동 저장됩니다. 다른 컴퓨터에서 이어 하려면 저장한 파일을 옮겨 파일 열기를 하세요.
  • 내용이 많으면 그 면의 글씨가 자동으로 조금씩 작아집니다. 너무 작아지면 위에 주황색 안내가 뜨니, 그때는 글을 줄여 주세요.
  • 표지 그림은 "표지" 칸에서 사진을 골라 바꿀 수 있습니다. 비워 두면 기본 그림이 들어갑니다.
  • 교회 주소·비전·선교지·예배 시간표처럼 잘 안 바뀌는 것은 맨 아래 고정 정보에 있습니다.
